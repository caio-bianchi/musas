# MUSAS documentation

User guide and API reference of **MUSAS** (Modular UTM Simulation and
Assessment System).

| File | Content |
|---|---|
| [`musas_documentation.pdf`](musas_documentation.pdf) | Full documentation: installation, quick start, simulation guide, API reference, custom algorithms, troubleshooting |
| [`getting_started.ipynb`](getting_started.ipynb) | Companion notebook with every listing of the quick start and *Going Further* chapters, already executed |
| `musas_documentation.tex` | LaTeX source of the PDF |
| `snippets/` | Code of the notebook cells; the PDF includes these same files, so both stay identical |
| `snippets/output/` | Printed output of each snippet, included in the PDF |
| `figures/` | Figures generated by the notebook and used in the PDF |
| `diagrams/` | TikZ architecture diagram |
| `tools/build_notebook.py` | Runs the snippets and rebuilds the notebook, outputs, and figures |

## Install MUSAS directly from Git

```bash
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install "git+https://github.com/caio-bianchi/musas.git"
```

Then import the package as `musas`:

```python
import musas
from musas.simulation import Simulation
```

A specific branch, tag, or commit can be installed with `@<ref>`, e.g.
`pip install "git+https://github.com/caio-bianchi/musas.git@main"`.
See Chapter 2 of the PDF for `requirements.txt`, `pyproject.toml`, Colab, and
editable installs.

## Run the getting-started notebook

```bash
pip install jupyter
cd documentation
jupyter notebook getting_started.ipynb
```

Run the notebook from this folder: it writes datasets to `outputs/` and
figures to `figures/`.

## Rebuild the documentation

Requirements: MUSAS installed in the active environment, a TeX distribution
with LuaLaTeX, and `Pygments` (used by `minted`). The fonts are Lato and
JetBrains Mono.

```bash
make notebook   # re-run the snippets, rebuild the notebook, outputs and figures
make pdf        # compile musas_documentation.pdf
```

To change an example, edit the file in `snippets/` and run both targets: the
notebook and the PDF are updated together.
